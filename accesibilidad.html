Declaración de Accesibilidad

Esta declaración es voluntaria: la normativa de accesibilidad web (Real Decreto 1112/2018) es de obligado cumplimiento para organismos del sector público, no para empresas privadas como Dreamscape Events and Complete Productions, S.L. Aun así, publicamos este resumen de las medidas que aplicamos por buenas prácticas.

Medidas aplicadas en este sitio:

  • Textos alternativos descriptivos en las imágenes y vídeos con contenido informativo.
  • Estructura semántica de encabezados (H1-H3) y uso de HTML5 y atributos ARIA en botones, menús y ventanas emergentes.
  • Navegación por teclado: los menús, el simulador y las ventanas emergentes se pueden cerrar con la tecla Escape.
  • Contraste de color cuidado entre texto y fondo en la mayoría de secciones.
  • Respeto a la preferencia de "movimiento reducido" del sistema operativo/navegador: si la tienes activada, las animaciones decorativas de la web se desactivan automáticamente.
  • Formularios con etiquetas asociadas a cada campo y validación con mensajes comprensibles.

Limitaciones conocidas: Algunos elementos visuales (como los vídeos de fondo o determinadas animaciones) pueden no cumplir al 100% con el nivel AA de las WCAG 2.1. Estamos abiertos a mejorar esta web de forma continua.

¿Detectas alguna barrera de accesibilidad? Escríbenos a info@ap-events.es y lo revisaremos con prioridad.
